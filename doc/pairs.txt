*pairs.nvim*  Conservative quote and bracket pairing for Neovim

Requires Neovim 0.11+. Pure Lua, no runtime dependencies.

SETUP                                                    *pairs-setup*

Disable other auto-pairs plugins, then: >lua
    require('pairs').setup({
      pairs = { ["'"] = { open = false } },
      treesitter = false,
    })
<
Handles Insert-mode (), [], {}, double and single quotes, matching closer
skipping, empty-pair <BS>, and empty-bracket expansion on <CR>.
<Tab> and other modes are not mapped.

Options:
  enabled              boolean or function(bufnr), default true
  mappings.enabled     install mappings, default true
  mappings.bs          install <BS> mapping, default true
  mappings.cr          install <CR> mapping, default true
  max_scan_bytes       maximum line prefix to scan, default 4096
  treesitter           use installed parsers for syntax context, default false
  disabled_filetypes   list of disabled filetypes
  pairs                table keyed by opening delimiter; false disables a rule
  multi_pairs          opt-in Python triple quotes, default {}
  filetypes            filetype -> { pairs, multi_pairs, enabled } overrides

Rules contain close (single ASCII character), open, skip, delete, and newline
(booleans). Open/skip/delete default to true for new rules. Newline defaults
to true for asymmetric pairs; symmetric quotes never expand. Overrides merge
with defaults.
Closing delimiters must be unique. Multi-character rules use multi_pairs.
Single-quote opening defaults to false in text, markdown, and rust.
Re-enabling a single-character rule disabled with false requires its close value.

Buffer overrides use b:pairs_enabled and b:pairs_rules. Buffer rules override
global and filetype rules; newly introduced delimiters need explicit mappings.

PYTHON TRIPLE QUOTES                                      *pairs-triples*

Opt-in, with treesitter=true and an installed Python parser: >lua
    require('pairs').setup({
      treesitter = true,
      filetypes = {
        python = {
          multi_pairs = {
            [string.rep('"', 3)] = {},
            [string.rep("'", 3)] = {},
          },
        },
      },
    })
<
Typing the third identical quote after a complete empty short string creates
a triple pair. Python r/u/b/f/br/rb/fr/rf prefixes are supported in either case.
At its real closing delimiter each quote press skips one quote. Body quotes
pass through. <BS> removes an adjacent empty triple pair; <CR> creates a middle
and closing line aligned with the opening line. Undo/redo and dot retain the
complete insertion.

Multi rules contain open, skip, delete, and newline, all defaulting to true.
The closer must equal the opener and may be omitted. false disables a rule.
Precedence is global multi_pairs, filetype multi_pairs, b:pairs_multi_rules.
Only Python triple quotes are supported. Missing/pending parser context cannot
trigger triple pairing; ordinary quote handling remains the fallback.

ENTER                                                    *pairs-enter*

<CR> between adjacent empty brackets creates an indented middle line and a
closing line. Strings, comments, quotes and nonempty pairs pass through.
Indentation uses indentexpr or cindent when configured. Otherwise it adds one
shiftwidth to the opening line and aligns the closer with that line. Tabs and
vartabstop are respected. Undo, redo and dot repeat retain the entire insertion;
dot replays the resulting indentation from the original insertion.

Existing Enter mappings are preserved. For a completion-owned Enter, set
mappings.cr=false and compose expr('<CR>') after completion confirmation and
before the owner's native fallback. See the blink.cmp example in README.md.

API                                                      *pairs-api*

setup(opts)            Validate config and install non-conflicting mappings.
expr(key)              Return handled keycodes, or nil for caller fallback.
handle(key)            Return handled or original keycodes.
explain(key, opts)     Return action/reason without editing; Insert mode by
                      default. opts.assume_insert previews insertion before
                      the Normal-mode cursor.
enable([bufnr])        Enable globally, or enable one buffer.
disable([bufnr])       Disable globally, or disable one buffer.
toggle([bufnr])        Toggle globally, or toggle one buffer.
status()              Initialization, global enabled state, mapping conflicts.
teardown()            Remove only mappings still owned by this plugin.

Use key notation such as '<BS>' or '<CR>'. expr()/handle() return termcodes; mappings
should use { expr = true, replace_keycodes = false }.
Plugin-owned mappings use <Ignore> before a private expression mapping to flush
preceding typed text. Composed mappings should consider |map-expression| order.

COMMANDS                                                 *pairs-commands*

:PairsToggle           Toggle pairing globally.
:PairsInspect {key}    Preview insertion before the cursor; does not edit text.
:checkhealth pairs     Inspect initialization and setup-time mapping conflicts.

LIMITS                                                   *pairs-limits*

The fallback lexer is line-local. It recognizes common line comments and basic
quoted strings, not complete language grammars. Escaping uses backslash parity;
non-ASCII neighbors conservatively block quote opening. Malformed bracket
prefixes and scans exceeding max_scan_bytes pass through.

treesitter=true protects raw/multiline strings and block comments. Python
f-string expressions and JavaScript/TypeScript template substitutions are code;
format/literal text stays protected. Completed string/comment nodes are masked
in the current line prefix before the lexer checks nesting.

Stale/unparsed trees are refreshed using Neovim's time-sliced parse callback
API. No full synchronous parse or wait is requested. Pending trees and unsafe
incomplete literals pass keys through. Missing parsers use the line-local lexer.
Current-line traversal is bounded to 256 nodes (syntax_limit on overflow).
This option does not install parsers or start highlighting. See README.md for
pinned parser fixtures used by the regression suite.

Existing global mappings are preserved; buffer mappings take precedence.
Paste, macro recording/replay, Replace mode, and special buffers bypass pairing.
Runtime context errors pass through and are exposed by explain().

Other multi-character pairs, wrapping and command-line mode are planned.
See README.md and docs/PLAN.md in the checkout for details.
